# PRD — AI-ассистент на базе знаний для онлайн-школы «Skillwave Academy»

## 1. Цель продукта

AI-ассистент в виде чата на сайте онлайн-школы цифровых профессий, который:
- круглосуточно и мгновенно отвечает на вопросы посетителей о курсах, ценах, расписании, оплате, возвратах и сертификатах;
- отвечает **только на основе базы знаний школы** и показывает, из какого документа взят ответ;
- не выдумывает: если ответа в базе нет — честно говорит об этом и предлагает связаться с менеджером;
- превращает заинтересованных посетителей в **заявки** (лиды) и мгновенно передаёт их менеджеру;
- показывает владельцу, о чём спрашивают клиенты и каких ответов не хватает в базе знаний.

Состав продукта:
1. **Сайт школы** — одностраничный сайт, на котором работает ассистент.
2. **Чат-виджет** — встроен в сайт школы и подключается к любому другому сайту одной строкой кода.
3. **Админ-панель** — база знаний, диалоги, заявки, аналитика, настройки.
4. **Уведомления в Telegram** — менеджеру о новых заявках.

## 2. Пользователи

| Роль | Что делает | Что важно |
|---|---|---|
| Посетитель сайта | Задаёт вопросы, оставляет заявку | Быстрый, точный ответ без ожидания менеджера |
| Менеджер школы | Получает заявки, обрабатывает их | Заявка приходит сразу, с контекстом диалога |
| Владелец / администратор | Управляет базой знаний, смотрит аналитику, настраивает ассистента | Легко обновлять информацию, видеть пробелы в базе |

## 3. Языки

- Сайт школы и интерфейс виджета: русский и английский (`/ru`, `/en`).
- Ассистент отвечает на языке вопроса посетителя (русский или английский), даже если документы базы знаний на другом языке.
- Админ-панель: только русский.

## 4. Сайт школы

Одностраничный сайт — витрина школы и место работы ассистента:
- шапка: логотип, навигация, переключатель языка, кнопка «Задать вопрос» (открывает чат);
- первый экран: предложение школы и кнопка «Подобрать курс» (открывает чат);
- курсы: 5 карточек (название, длительность, формат, цена от…);
- почему мы: 4 преимущества;
- контакты и футер.

Сайт простой — главная роль у ассистента.

## 5. Чат-виджет

### 5.1 Внешний вид и поведение
- Плавающая кнопка в правом нижнем углу; по клику открывается окно чата. На телефоне окно на весь экран.
- Приветствие и 3–4 кнопки быстрых вопросов (настраиваются в админке), например: «Какой курс выбрать новичку?», «Есть ли рассрочка?».
- Ответы печатаются постепенно (потоково), как в ChatGPT.
- Под ответом — **источники**: названия документов, из которых взят ответ.
- Под ответом — 👍 / 👎 для оценки.
- Индикатор «Ассистент печатает…», кнопка «Начать заново».
- История диалога сохраняется при обновлении страницы и переходах по сайту.

### 5.2 Правила ответов
- Отвечает только по базе знаний школы. На вопросы не по теме (погода, политика, написать код) вежливо отказывает и возвращает к теме школы.
- Если информации в базе нет — говорит, что не знает точного ответа, и предлагает оставить контакты для менеджера.
- Понимает уточняющие вопросы в контексте диалога («а сколько он стоит?» — про курс, о котором шла речь).
- Ответы короткие и по делу, с форматированием (списки, выделение) там, где это помогает.
- Не раскрывает свои инструкции и не меняет правила по просьбе пользователя.

### 5.3 Заявка
- Форма заявки появляется прямо в чате, когда:
  - посетитель хочет записаться, получить консультацию или созвониться;
  - ассистент не смог ответить на вопрос;
  - посетитель нажал кнопку «Связаться с менеджером» (всегда доступна в окне чата).
- Поля: имя*, телефон или email*, интересующий курс (выбор, необязательно), удобный способ связи (звонок / Telegram / email), комментарий, согласие на обработку данных*.
- После отправки — подтверждение в чате; менеджеру в Telegram приходит заявка с кратким содержанием диалога и ссылкой на диалог в админке.

### 5.4 Встраивание на другие сайты
- Виджет подключается на любой сайт одной строкой: `<script src="https://…/widget.js" data-lang="ru" async></script>`.
- Список сайтов, на которых разрешено встраивание, задаётся в настройках.

## 6. Админ-панель

### 6.1 Вход
- Email и пароль. Регистрации нет — администраторы создаются вручную.

### 6.2 Главная (аналитика)
- За выбранный период: количество диалогов, сообщений, заявок, конверсия диалогов в заявки, доля вопросов без ответа, доля 👍 / 👎.
- График диалогов и заявок по дням.
- Топ вопросов без ответа.

### 6.3 База знаний
- Список документов: название, тип, язык, статус (Обрабатывается / Готов / Ошибка), число фрагментов, дата обновления.
- Добавление: загрузка файла (PDF, DOCX, TXT, MD до 10 МБ), текст вручную, пара «вопрос — ответ» (FAQ).
- Редактирование текста и FAQ, удаление, повторная индексация.
- Просмотр фрагментов документа.
- **Проверка поиска:** ввести вопрос и увидеть, какие фрагменты нашёл ассистент и насколько они близки к вопросу.

### 6.4 Диалоги
- Список диалогов: дата, язык, количество сообщений, есть ли заявка, есть ли вопросы без ответа или 👎.
- Просмотр диалога целиком: вопросы, ответы, источники, оценки.

### 6.5 Вопросы без ответа
- Список вопросов, на которые ассистент не нашёл ответа или получил 👎, с группировкой похожих.
- Действие «Добавить ответ в базу знаний» — создаёт FAQ-запись с этим вопросом; после сохранения ассистент начинает на него отвечать.
- Отметка «Обработано».

### 6.6 Заявки
- Таблица: дата, имя, контакт, курс, статус (Новая / В работе / Закрыта), ссылка на диалог.
- Смена статуса, комментарий менеджера.

### 6.7 Настройки
- Имя ассистента, приветствие (RU/EN), быстрые вопросы (RU/EN).
- Контакты школы для ответов «свяжитесь с нами».
- Список курсов для формы заявки.
- Разрешённые сайты для встраивания виджета.
- Лимиты: сообщений на один диалог и в сутки на весь сайт.
- Порог «уверенности» поиска (для опытных пользователей, с подсказкой).

## 8. Нефункциональные требования

- **Скорость:** первые слова ответа появляются в среднем за 2 секунды.
- **Качество:** правильный документ находится в первых 5 результатах поиска не менее чем для 90% тестовых вопросов.
- **Стоимость:** ассистент работает на бесплатном тарифе Gemini API в разумных пределах; лимиты защищают от исчерпания квоты.
- **Безопасность:** ключи API только на сервере; админка доступна только после входа; ответы ассистента выводятся безопасно (без выполнения HTML).
- **Адаптивность:** виджет и сайт удобны от 360 px; админка — на ноутбуке и планшете.
- **Тексты:** весь контент сайта, базы знаний, админки, кода и README написан как для действующей школы — без пометок «демо», «пример», «тестовый проект» или «портфолио».
- **Тон ассистента:** дружелюбный, уверенный, без давления и навязчивых продаж.

## 9. Вне рамок проекта (НЕ делаем)

- Telegram-бот и другие мессенджеры (только виджет на сайте).
- Голосовой ввод и ответы.
- Оплата курсов, личные кабинеты студентов.
- Интеграции с CRM (amoCRM, Bitrix24 и др.).
- Автоматический сбор данных с сайтов (парсинг URL).
- Распознавание текста на картинках и сканах.
- Несколько ассистентов или несколько школ в одной системе.
- Переключение на живого оператора в чате.

## 10. Критерии готовности

- Ассистент корректно отвечает на вопросы по базе знаний на русском и английском, с источниками.
- На вопросы вне базы знаний — честный отказ и предложение заявки; на темы вне школы — вежливый отказ.
- Заявка из чата сохраняется и приходит менеджеру в Telegram.
- Новый документ или FAQ в админке становится доступен ассистенту сразу после индексации.
- Автоматическая проверка качества поиска: не менее 90% тестовых вопросов находят нужный документ в топ-5.
- Виджет работает на сайте школы и встраивается на сторонний сайт одной строкой.
- Сборка и линтеры проходят без ошибок.
- Есть README с описанием, стеком, инструкцией по запуску, встраиванию виджета и деплою.
