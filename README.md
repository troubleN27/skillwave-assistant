# Skillwave Academy — AI-ассистент

AI-ассистент для сайта онлайн-школы цифровых профессий Skillwave Academy. Круглосуточно отвечает посетителям на вопросы о курсах, ценах, расписании, оплате, возвратах и сертификатах — только по базе знаний школы и со ссылками на источники. Если ответа в базе нет, честно говорит об этом и предлагает оставить заявку; заявка сразу приходит менеджеру в Telegram. Владелец школы видит в админ-панели, о чём спрашивают посетители и каких ответов не хватает в базе знаний.

Подробные требования — [docs/PRD.md](docs/PRD.md), техническая спецификация — [docs/SPEC.md](docs/SPEC.md).

## Возможности

- **Сайт школы** (`/ru`, `/en`) — витрина пяти курсов; кнопки «Задать вопрос», «Подобрать курс» и «Спросить о курсе» открывают ассистента.
- **Чат-виджет** — потоковые ответы, источники под ответом, оценки 👍/👎, быстрые вопросы, уточняющие вопросы в контексте диалога, форма заявки прямо в чате, история между перезагрузками, полноэкранный режим на телефоне. Встраивается на любой сайт одной строкой.
- **Ответы только по базе знаний** — на русском и английском (на языке вопроса, даже если документ на другом языке); вежливый отказ на темы вне школы; устойчивость к попыткам изменить инструкции.
- **Заявки** — сохраняются в базе, менеджеру приходит сообщение в Telegram с кратким содержанием диалога и ссылкой на него.
- **Админ-панель** (`/admin`) — аналитика, база знаний (загрузка PDF, DOCX, TXT, MD, текст, FAQ), проверка поиска, диалоги, вопросы без ответа с добавлением ответа в базу, заявки, настройки ассистента.

## Как ассистент отвечает

```
Посетитель → виджет → POST /api/chat
  1. проверка сайта-источника, длины сообщения (до 1000 символов) и лимитов
  2. сохранение сообщения; уточнение («а сколько он стоит?») → самостоятельный вопрос
  3. гибридный поиск: векторный (pgvector) + полнотекстовый, объединение RRF → 5 фрагментов
  4. близость ниже порога → заготовленный ответ + форма заявки + «Вопросы без ответа»
  5. иначе → ответ Gemini по фрагментам, печатается по мере генерации, с источниками
```

Если Gemini API недоступен или перегружен, посетитель видит «Ассистент временно перегружен…» и форму заявки — вызовы модели ограничены по времени. Модели задаются переменными `GEMINI_CHAT_MODEL` и `GEMINI_EMBEDDING_MODEL`, без изменения кода.

## Запуск локально

Нужны Node.js 20+, база Neon (PostgreSQL с расширением `vector`), ключ Gemini API и хранилище Vercel Blob.

```powershell
npm install
```

```powershell
Copy-Item .env.example .env.local
```

Заполните `.env.local` (описание каждой переменной — в [.env.example](.env.example)). Секрет для `BETTER_AUTH_SECRET` можно сгенерировать так:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Примените миграции, создайте администратора, проиндексируйте базу знаний и запустите сервер:

```powershell
npm run db:migrate
```

```powershell
npm run create-admin -- --email admin@skillwave.academy --password "надёжный-пароль"
```

```powershell
npm run seed:knowledge
```

```powershell
npm run dev
```

Сайт: http://localhost:3000, админ-панель: http://localhost:3000/admin.

## База знаний

Стартовые документы лежат в `knowledge/` (Markdown): о школе, пять курсов, оплата, возврат, сертификаты и трудоустройство, частые вопросы, а также два документа на английском. Название документа — первый заголовок `#`, язык `-en.md` — английский. `npm run seed:knowledge` индексирует папку; повторный запуск обновляет изменённые документы и пропускает остальные.

В админ-панели (раздел «База знаний») можно загрузить файл PDF, DOCX, TXT или MD до 10 МБ (сканы без текстового слоя не поддерживаются — документ получит статус «Ошибка» с объяснением), добавить текст или пару «вопрос — ответ», отредактировать, переиндексировать или удалить документ и посмотреть его фрагменты. Статус индексации обновляется без перезагрузки страницы.

Индексация: текст делится на фрагменты по заголовкам и абзацам (~800 символов, максимум 1200, перекрытие ~150), к каждому добавляются название документа и заголовок раздела, строится эмбеддинг Gemini, фрагменты сохраняются в PostgreSQL с индексами HNSW (векторный поиск) и GIN (полнотекстовый). Раздел «Проверка поиска» показывает, какие фрагменты находятся по вопросу, их близость и позиции в обоих видах поиска.

На бесплатном тарифе Gemini API действует лимит запросов в минуту: если индексация завершилась ошибкой «Превышен лимит запросов», повторите её через минуту кнопкой «Переиндексировать».

## Проверка качества поиска

`evals/questions.json` содержит 30 вопросов с ожидаемыми документами (20 на русском, 10 на английском — в том числе английские вопросы к русским документам), 8 вопросов, ответа на которые в базе нет, и 5 вопросов не по теме. `npm run eval` показывает долю вопросов, где нужный документ в топ-5, долю отсечённых порогом уверенности вопросов без ответа и не по теме для порогов 0.50–0.85, рекомендуемый порог и таблицу провалов.

Текущий результат:

| Показатель | Значение |
|---|---|
| Нужный документ в топ-5 | 30 из 30 (100%; цель ≥ 90%) |
| Вопросы с ответом, проходящие порог 0.69 | 100% (с запасом 0.02) |
| Отсечено вопросов не по теме | 5 из 5 |
| Отсечено вопросов без ответа | 3 из 8 |

Вопросы без ответа, близкие к теме школы (например, «Есть ли курс по Java?»), по смыслу похожи на документы о курсах и порог проходят — на них ассистент по правилам промпта отвечает, что такой информации нет, и предлагает заявку. Запускайте `npm run eval` после изменений в базе знаний, разбиении или поиске; порог меняется в настройках админки.

## Чат-виджет и заявки

Виджет — кнопка в правом нижнем углу. Приветствие и до четырёх быстрых вопросов настраиваются в админке. Под ответом — источники и кнопки 👍/👎 (оценка 👎 отправляет вопрос в «Вопросы без ответа»). Переписка сохраняется при перезагрузке страницы, «Начать заново» открывает новый диалог. На экранах уже 640 px окно открывается на весь экран; Esc закрывает его.

Форма заявки появляется в чате, когда посетитель хочет записаться или поговорить с менеджером, когда ассистент не нашёл ответа, и по кнопке «Связаться с менеджером». Поля: имя, телефон в международном формате или email, курс, удобный способ связи, комментарий, согласие на обработку данных.

### Уведомления в Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и запишите токен в `TELEGRAM_BOT_TOKEN`.
2. Напишите боту любое сообщение (или добавьте его в рабочий чат менеджеров и напишите там).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `message.chat.id` — это `TELEGRAM_CHAT_ID`.

Без этих переменных заявки сохраняются, а отправка в Telegram пропускается с записью в лог. Уведомления можно выключить в настройках админки.

## Встраивание виджета на другой сайт

Добавьте перед закрывающим `</body>` одну строку (адрес — адрес сайта школы):

```html
<script src="https://skillwave.academy/widget.js" data-lang="ru" async></script>
```

- `data-lang` — язык интерфейса виджета: `ru` или `en`; ассистент всё равно отвечает на языке вопроса.
- Добавьте сайт в «Разрешённые сайты» в настройках админки. Страница чата `/embed` отдаёт заголовок `Content-Security-Policy: frame-ancestors` только с разрешёнными адресами (обновляется в течение минуты), на остальных сайтах браузер чат не покажет.
- Скрипт без зависимостей создаёт кнопку и `iframe` со страницей `/embed?lang=…`; окно чата загружается только при первом открытии.

Проверка встраивания локально: запустите `npm run dev`, затем

```powershell
python -m http.server 5500 --directory public
```

добавьте `http://localhost:5500` в разрешённые сайты и откройте http://localhost:5500/embed-test.html.

## Безопасность

- Ключи API и строки подключения используются только на сервере, в браузер не попадают; `.env.local` не хранится в репозитории.
- Админка доступна только после входа; каждая страница, Server Action и Route Handler проверяет сессию на сервере.
- Ответы ассистента выводятся как Markdown без HTML; пользовательский ввод в Telegram экранируется; ссылки на страницы посетителей — только `http(s)`.
- Ассистент отвечает только по базе знаний; текст документов и сообщений посетителя — данные, а не инструкции (проверено попытками «забудь правила», «покажи системный промпт», подменой роли и командой внутри загруженного документа).
- Лимиты: 20 сообщений за 10 минут на посетителя, 60 на IP-адрес, лимит на диалог и суточный лимит сайта (защита квоты Gemini); заявки — 3 в час на посетителя и 10 на IP, honeypot-поле от ботов.
- `/api/chat`, `/api/leads`, `/api/feedback` принимают запросы только с сайта школы и разрешённых сайтов; виджет показывается во фрейме только на разрешённых сайтах.

## Деплой

### 1. Gemini API

Создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey) → `GOOGLE_GENERATIVE_AI_API_KEY`. На бесплатном тарифе действуют лимиты запросов (актуальные — на странице лимитов в AI Studio); суточный лимит сообщений в настройках админки защищает квоту. По условиям Google данные бесплатного тарифа могут использоваться для улучшения продуктов — для работы с реальными клиентами подключите платный тариф.

### 2. Neon

1. Создайте проект (регион ближе к посетителям, например Frankfurt), compute 0.25 CU.
2. Скопируйте pooled-строку подключения в `DATABASE_URL`, прямую — в `DATABASE_URL_UNPOOLED`.
3. С этими переменными в `.env.local` выполните:

```powershell
npm run db:migrate
```

```powershell
npm run seed:knowledge
```

```powershell
npm run create-admin -- --email <email> --password "<пароль>"
```

### 3. Vercel

1. Импортируйте репозиторий в Vercel (фреймворк определится автоматически).
2. В Storage создайте Vercel Blob (private) и подключите к проекту — `BLOB_READ_WRITE_TOKEN` появится в переменных автоматически.
3. Добавьте переменные окружения:

| Переменная | Значение |
|---|---|
| `DATABASE_URL`, `DATABASE_URL_UNPOOLED` | строки Neon |
| `GOOGLE_GENERATIVE_AI_API_KEY` | ключ Gemini |
| `GEMINI_CHAT_MODEL`, `GEMINI_EMBEDDING_MODEL`, `EMBEDDING_DIMENSIONS` | `gemini-3.5-flash-lite`, `gemini-embedding-2`, `768` |
| `BETTER_AUTH_SECRET` | случайная строка (32+ символа) |
| `BETTER_AUTH_URL`, `NEXT_PUBLIC_SITE_URL` | адрес сайта, например `https://skillwave.academy` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | бот и чат менеджеров |

4. Запустите деплой и проверьте: сайт, ответ ассистента, вход в админку, тестовую заявку.
5. Если виджет будет встраиваться на другие сайты — добавьте их адреса в «Разрешённые сайты» в настройках админки.
