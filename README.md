# Skillwave Academy — AI-ассистент

AI-ассистент для сайта онлайн-школы цифровых профессий Skillwave Academy. Круглосуточно отвечает посетителям на вопросы о курсах, ценах, расписании, оплате, возвратах и сертификатах — только по базе знаний школы и со ссылками на источники. Если ответа в базе нет, честно говорит об этом и предлагает оставить заявку менеджеру.

Состав:

- **Сайт школы** (`/ru`, `/en`) — витрина курсов, на которой работает ассистент.
- **Чат-виджет** — встроен в сайт и подключается к другим сайтам одной строкой кода.
- **Админ-панель** (`/admin`) — база знаний, диалоги, заявки, аналитика, настройки.
- **Уведомления в Telegram** — менеджеру о новых заявках.

Подробные требования — [docs/PRD.md](docs/PRD.md), техническая спецификация — [docs/SPEC.md](docs/SPEC.md).

## Стек

- Next.js 16 (App Router, TypeScript), Tailwind CSS 4, shadcn/ui, lucide-react
- next-intl — русский и английский
- Neon (PostgreSQL) + pgvector, Drizzle ORM и drizzle-kit
- Better Auth — вход в админку по email и паролю
- Gemini API через Vercel AI SDK
- Vitest

## Запуск локально

Нужны Node.js 20+ и база Neon с поддержкой расширения `vector`.

```powershell
npm install
Copy-Item .env.example .env.local
```

Заполните в `.env.local` как минимум `DATABASE_URL` (pooled-строка Neon), `DATABASE_URL_UNPOOLED` (прямая строка, для миграций), `BETTER_AUTH_SECRET`, `GOOGLE_GENERATIVE_AI_API_KEY` (ключ из Google AI Studio) и `BLOB_READ_WRITE_TOKEN` (токен private-хранилища Vercel Blob — нужен для загрузки файлов в базу знаний). Секрет можно сгенерировать так:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Примените миграции, создайте администратора и запустите сервер:

```powershell
npm run db:migrate
```

```powershell
npm run create-admin -- --email admin@skillwave.academy --password "надёжный-пароль"
```

```powershell
npm run seed:knowledge
```

```powershell
npm run dev
```

Сайт: http://localhost:3000, админ-панель: http://localhost:3000/admin.

## База знаний

Ассистент отвечает только по документам базы знаний. Стартовые документы лежат в `knowledge/` (Markdown): о школе, пять курсов, оплата, возврат, сертификаты и трудоустройство, частые вопросы, а также два документа на английском. Команда `npm run seed:knowledge` индексирует их; повторный запуск обновляет изменённые документы и пропускает остальные.

В админ-панели (раздел «База знаний») можно:

- загрузить файл PDF, DOCX, TXT или MD до 10 МБ (сканы без текстового слоя не поддерживаются);
- добавить текст вручную или пару «вопрос — ответ» (FAQ);
- отредактировать, переиндексировать или удалить документ и посмотреть его фрагменты.

Как работает индексация: текст делится на фрагменты по заголовкам и абзацам (~800 символов, перекрытие ~150), для каждого фрагмента строится эмбеддинг Gemini (768 измерений), фрагменты сохраняются в PostgreSQL с pgvector. Поиск гибридный: векторный и полнотекстовый, результаты объединяются методом Reciprocal Rank Fusion. Раздел «Проверка поиска» показывает, какие фрагменты находятся по вопросу и насколько они близки к нему.

На бесплатном тарифе Gemini API действует лимит запросов в минуту. Если индексация документа завершилась ошибкой «Превышен лимит запросов», повторите её через минуту — кнопкой «Переиндексировать» или повторным запуском `seed:knowledge`.

## Как ассистент отвечает

На каждое сообщение посетителя сервер (`POST /api/chat`):

1. проверяет сайт-источник, длину сообщения (до 1000 символов) и лимиты: 20 сообщений за 10 минут на посетителя, лимит на диалог и на сутки для всего сайта (настраиваются в админке);
2. сохраняет сообщение и, если это уточнение («а сколько он стоит?»), переформулирует его в самостоятельный вопрос с учётом последних сообщений диалога;
3. ищет подходящие фрагменты в базе знаний;
4. если близких фрагментов нет (близость ниже порога уверенности), отвечает заготовленным текстом на языке посетителя, предлагает оставить заявку и записывает вопрос в «Вопросы без ответа»;
5. иначе генерирует короткий ответ по найденным фрагментам и показывает его по мере печати, вместе со списком источников.

Ассистент отвечает на языке вопроса, отказывается от тем, не связанных со школой, не раскрывает свои инструкции и предлагает форму заявки, когда посетитель хочет записаться или поговорить с менеджером. Если Gemini API временно недоступен, посетитель видит сообщение «Ассистент временно перегружен…» и форму заявки.

Модель ответов задаётся переменной `GEMINI_CHAT_MODEL` (по умолчанию `gemini-3.5-flash-lite`), модель эмбеддингов — `GEMINI_EMBEDDING_MODEL`.

## Проверка качества поиска

В `evals/questions.json` — 30 вопросов с ожидаемыми документами (20 на русском, 10 на английском, в том числе английские вопросы к русским документам), 8 вопросов, ответа на которые в базе нет, и 5 вопросов не по теме. Команда `npm run eval` показывает:

- долю вопросов, для которых нужный документ попал в топ-5 (цель — не меньше 90%);
- для разных порогов уверенности — сколько вопросов с ответом проходит и сколько вопросов без ответа и не по теме отсекается;
- рекомендуемый порог и список провалов для разбора.

Текущий результат: нужный документ в топ-5 у 30 из 30 вопросов; порог 0.69 пропускает все вопросы с ответом с запасом и отсекает все вопросы не по теме. Вопросы без ответа, близкие к теме школы (например, «Есть ли курс по Java?»), порогом не отсекаются — на них ассистент честно отвечает, что такой информации нет, и предлагает заявку. Запускайте `npm run eval` после изменений в базе знаний, разбиении или поиске; порог меняется в настройках админки.

## Чат-виджет и заявки

Виджет — плавающая кнопка в правом нижнем углу сайта. Он показывает приветствие и быстрые вопросы (настраиваются в админке), печатает ответы по мере генерации, под ответом показывает источники и кнопки 👍/👎. Переписка сохраняется при перезагрузке страницы, кнопка «Начать заново» открывает новый диалог. На экранах уже 640 px окно чата открывается на весь экран.

Форма заявки появляется прямо в чате: когда посетитель хочет записаться или поговорить с менеджером, когда ассистент не нашёл ответа, и по кнопке «Связаться с менеджером». Поля: имя, телефон (в международном формате) или email, курс, удобный способ связи, комментарий и согласие на обработку данных. Заявка сохраняется в базе, а менеджеру приходит сообщение в Telegram с кратким содержанием диалога и ссылкой на него в админке.

### Уведомления в Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен в `TELEGRAM_BOT_TOKEN`.
2. Напишите боту любое сообщение (или добавьте его в рабочий чат менеджеров и напишите там).
3. Узнайте id чата: откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите значение `message.chat.id` — это `TELEGRAM_CHAT_ID`.

Если переменные не заданы, заявки сохраняются, а отправка в Telegram пропускается с записью в лог сервера.

## Встраивание виджета на другой сайт

Добавьте перед закрывающим `</body>` одну строку (замените адрес на адрес сайта школы):

```html
<script src="https://skillwave.academy/widget.js" data-lang="ru" async></script>
```

- `data-lang` — язык интерфейса виджета: `ru` или `en`. Ассистент всё равно отвечает на языке вопроса.
- Сайт, на который встраивается виджет, нужно добавить в список разрешённых сайтов в настройках админки (поле `allowed_origins`). Для остальных сайтов браузер не покажет чат: страница `/embed` отдаёт заголовок `Content-Security-Policy: frame-ancestors` только с разрешёнными адресами.
- Скрипт без зависимостей создаёт кнопку и `iframe` со страницей `/embed?lang=…`; окно чата загружается только при первом открытии.

Проверить встраивание локально:

```powershell
npm run dev
```

```powershell
python -m http.server 5500 --directory public
```

Добавьте `http://localhost:5500` в разрешённые сайты и откройте http://localhost:5500/embed-test.html.

## База данных

Схема описана в `src/db/schema.ts`, миграции лежат в `db/migrations/`:

- `0000_enable_pgvector` — расширение `vector`;
- `0001_initial_schema` — таблицы, индексы HNSW (векторный поиск) и GIN (полнотекстовый поиск), генерируемая колонка `chunks.tsv`;
- `0002_default_settings` — настройки ассистента по умолчанию;
- `0003_tune_min_similarity`, `0004_default_contacts` — порог уверенности поиска и контакты школы для ответов.

Регистрация в админке отключена: администраторы создаются только командой `create-admin`.
