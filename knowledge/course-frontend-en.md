# Frontend Developer course

## Who the course is for

- Beginners who want to learn web development from scratch and get their first job in IT.
- People who have already tried learning HTML and JavaScript on their own and want to structure their knowledge with a mentor.
- Designers, layout developers and testers who want to move into frontend development.

No programming experience is needed: the course starts from the basics.

## Program by module

### Module 1. Web basics and layout

How websites and browsers work, HTML and CSS, semantic markup, Flexbox and Grid, responsive layouts for phones and tablets, working with Figma mockups. Introduction to Git and GitHub.

### Module 2. JavaScript

Variables, data types, functions, arrays and objects, working with the DOM and events, asynchronous code, promises and async/await, server requests with fetch, working with JSON.

### Module 3. TypeScript and developer tools

Typing in TypeScript, bundlers (Vite), the npm package manager, linters and code formatting, testing basics.

### Module 4. React

Components and JSX, state and hooks, routing, forms, application state management, API requests.

### Module 5. Next.js and advanced development

Next.js and server-side rendering, performance optimisation, interface accessibility, deploying projects to hosting.

### Module 6. Final project and job preparation

Team development of a final project based on a real technical brief, code review, CV and portfolio preparation, mock technical interviews.

## Duration, format and schedule

The course lasts **9 months**. Learning is online: recorded video lessons, live webinars twice a week — on Tuesdays and Thursdays at 7 pm Moscow time, and practical assignments reviewed by a mentor. The recommended workload is 8–10 hours a week.

## Portfolio projects

During the course you will build 6 projects:

1. A responsive landing page based on a Figma mockup.
2. An interactive JavaScript web app (a task tracker).
3. A movie search app that works with an API.
4. A React online store with a cart and filters.
5. A multi-page website on Next.js.
6. A final team project on a brief from a real client.
