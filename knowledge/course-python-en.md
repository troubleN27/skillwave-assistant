# Python Developer course

## Who the course is for

- Beginners with no programming experience who want to become backend developers.
- Specialists from other fields who want to automate their work and move into IT.
- Junior programmers who need a solid foundation and experience with real projects.

## Program by module

### Module 1. Python basics

Language syntax, data types, conditions and loops, functions, working with files, error handling, modules and packages. Git and the command line.

### Module 2. Object-oriented programming

Classes and objects, inheritance, encapsulation, polymorphism, clean code principles, testing with pytest.

### Module 3. Databases and SQL

Relational databases, PostgreSQL, SQL queries, data schema design, working with a database from Python through an ORM.

### Module 4. Web development with Django

How web applications work, Django, models, views and templates, user authentication, the admin panel.

### Module 5. APIs and asynchronous programming

REST APIs with Django REST Framework and FastAPI, asynchronous programming, working with external services, Telegram bots.

### Module 6. Infrastructure and deployment

Linux, Docker, task queues, caching, deploying applications to a server, CI/CD basics.

### Module 7. Final project and job preparation

A team backend project, code review, CV and GitHub portfolio preparation, mock technical interviews.

## Duration, format and schedule

The course lasts **10 months**. Learning is online: recorded video lessons, live webinars twice a week — on Tuesdays and Thursdays at 7 pm Moscow time, and practical assignments with mentor code reviews. The recommended workload is 10 hours a week.

## Portfolio projects

During the course you will build 5 projects:

1. A Telegram bot for booking services.
2. A blog platform on Django with authentication and comments.
3. A REST API for a delivery service on FastAPI.
4. A data scraping and analysis service with background tasks.
5. A final team project on a brief from a real client.
