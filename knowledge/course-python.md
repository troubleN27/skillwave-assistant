# Курс «Python-разработчик»

## Для кого курс

- Для новичков без опыта программирования, которые хотят стать backend-разработчиками.
- Для специалистов из других сфер, которые хотят автоматизировать работу и перейти в IT.
- Для начинающих программистов, которым нужна системная база и опыт реальных проектов.

## Программа по модулям

### Модуль 1. Основы Python

Синтаксис языка, типы данных, условия и циклы, функции, работа с файлами, обработка ошибок, модули и пакеты. Git и командная строка.

### Модуль 2. Объектно-ориентированное программирование

Классы и объекты, наследование, инкапсуляция, полиморфизм, принципы чистого кода, тестирование с pytest.

### Модуль 3. Базы данных и SQL

Реляционные базы данных, PostgreSQL, SQL-запросы, проектирование схемы данных, работа с базой из Python через ORM.

### Модуль 4. Веб-разработка на Django

Устройство веб-приложений, Django, модели, представления и шаблоны, авторизация пользователей, админ-панель.

### Модуль 5. API и асинхронность

REST API на Django REST Framework и FastAPI, асинхронное программирование, работа с внешними сервисами, Telegram-боты.

### Модуль 6. Инфраструктура и деплой

Linux, Docker, очереди задач, кэширование, деплой приложений на сервер, основы CI/CD.

### Модуль 7. Дипломный проект и подготовка к работе

Командный backend-проект, код-ревью, подготовка резюме и портфолио на GitHub, тренировочные технические собеседования.

## Длительность, формат и расписание

Курс длится **10 месяцев**. Обучение онлайн: видеоуроки в записи, живые вебинары два раза в неделю — по вторникам и четвергам в 19:00 по московскому времени, практические задания с код-ревью наставника. Рекомендуемая нагрузка — 10 часов в неделю.

## Проекты в портфолио

За время курса вы создадите 5 проектов:

1. Telegram-бот для записи на услуги.
2. Блог-платформа на Django с авторизацией и комментариями.
3. REST API для сервиса доставки на FastAPI.
4. Сервис парсинга и анализа данных с отложенными задачами.
5. Дипломный командный проект по заданию реального заказчика.
