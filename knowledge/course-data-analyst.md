# Курс «Аналитик данных»

## Для кого курс

- Для новичков, которые хотят работать с данными и помогать компаниям принимать решения на основе цифр.
- Для экономистов, маркетологов и менеджеров, которые много работают с Excel и хотят освоить профессиональные инструменты.
- Для тех, кто хочет войти в IT через аналитику без глубокого программирования.

Высшая математика не нужна: всю необходимую статистику разбираем на курсе с нуля.

## Программа по модулям

### Модуль 1. Excel и Google Таблицы

Формулы и функции, сводные таблицы, очистка данных, визуализация, основы финансового и продуктового анализа.

### Модуль 2. SQL

Запросы к базам данных, фильтрация, группировка и агрегация, объединение таблиц, оконные функции, работа с PostgreSQL и ClickHouse.

### Модуль 3. Python для анализа данных

Основы Python, библиотеки pandas и NumPy, обработка и очистка данных, визуализация в matplotlib и seaborn, работа в Jupyter Notebook.

### Модуль 4. Статистика и A/B-тесты

Описательная статистика, распределения, проверка гипотез, проектирование и анализ A/B-тестов.

### Модуль 5. Продуктовая аналитика и BI

Продуктовые метрики (retention, LTV, конверсия, когортный анализ), построение дашбордов в DataLens и Power BI, юнит-экономика.

### Модуль 6. Дипломный проект и карьера

Аналитическое исследование на реальных данных компании-партнёра, презентация выводов, подготовка резюме и портфолио, тренировочные собеседования.

Курс длится **8 месяцев**. Обучение онлайн: видеоуроки в записи, живые вебинары два раза в неделю — по понедельникам и средам в 19:00 по московскому времени, практические задания с проверкой наставником. Рекомендуемая нагрузка — 8–10 часов в неделю.

## Проекты в портфолио

За время курса вы выполните 5 проектов:

1. Анализ продаж интернет-магазина в Excel.
2. Исследование пользовательской базы с помощью SQL.
3. Анализ поведения пользователей мобильного приложения на Python.
4. Дашборд ключевых метрик продукта.
5. Дипломное исследование на данных компании-партнёра.
