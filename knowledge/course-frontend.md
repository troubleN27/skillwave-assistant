# Курс «Frontend-разработчик»

## Для кого курс

- Для новичков, которые хотят с нуля освоить профессию веб-разработчика и найти первую работу в IT.
- Для тех, кто уже пробовал изучать HTML и JavaScript самостоятельно и хочет систематизировать знания под руководством наставника.
- Для дизайнеров, верстальщиков и тестировщиков, которые хотят перейти во frontend-разработку.

Опыт программирования не нужен: курс начинается с основ.

## Программа по модулям

### Модуль 1. Основы веба и вёрстка

Как устроены сайты и браузер, HTML и CSS, семантическая вёрстка, Flexbox и Grid, адаптивная вёрстка под телефоны и планшеты, работа с макетами в Figma. Знакомство с Git и GitHub.

### Модуль 2. JavaScript

Переменные, типы данных, функции, массивы и объекты, работа с DOM и событиями, асинхронность, промисы и async/await, запросы к серверу через fetch, работа с JSON.

### Модуль 3. TypeScript и инструменты разработчика

Типизация в TypeScript, сборщики (Vite), пакетный менеджер npm, линтеры и форматирование кода, основы тестирования.

### Модуль 4. React

Компоненты и JSX, состояние и хуки, маршрутизация, работа с формами, управление состоянием приложения, запросы к API.

### Модуль 5. Next.js и продвинутая разработка

Next.js и серверный рендеринг, оптимизация производительности, доступность интерфейсов, деплой проектов на хостинг.

### Модуль 6. Дипломный проект и подготовка к работе

Командная разработка дипломного проекта по реальному техническому заданию, код-ревью, подготовка резюме и портфолио, тренировочные технические собеседования.

## Длительность, формат и расписание

Курс длится **9 месяцев**. Обучение онлайн: видеоуроки в записи, живые вебинары два раза в неделю — по вторникам и четвергам в 19:00 по московскому времени, практические задания с проверкой наставником. Рекомендуемая нагрузка — 8–10 часов в неделю.

## Проекты в портфолио

За время курса вы создадите 6 проектов:

1. Адаптивный лендинг по макету из Figma.
2. Интерактивное веб-приложение на JavaScript (трекер задач).
3. Приложение для поиска фильмов с работой через API.
4. Интернет-магазин на React с корзиной и фильтрами.
5. Многостраничный сайт на Next.js.
6. Дипломный командный проект по заданию реального заказчика.
