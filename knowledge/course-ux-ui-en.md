# UX/UI Designer course

## Who the course is for

- Beginners who want to learn interface design from scratch.
- Graphic designers, illustrators and web designers who want to move into product design.
- Managers and marketers who need to understand how convenient websites and apps are designed.

You do not need to be able to draw: interface design is above all about logic, research and working with a grid.

## Program by module

### Module 1. UX basics and research

What user experience is, user interviews, personas and scenarios, the customer journey map (CJM), competitor analysis.

### Module 2. Interface design

Information architecture, user flows, wireframes and prototypes, usability testing.

### Module 3. Figma and visual design

Figma from scratch, composition, grids, typography, colour, auto layout and components, design systems.

### Module 4. Website and mobile app design

Responsive website design, iOS and Android guidelines, interactive prototypes, interface animation, handing off designs to developers.

### Module 5. Final project and career

A full-cycle project — from research to a finished prototype, Behance case studies, portfolio and CV preparation, mock interviews.

## Duration, format and schedule

The course lasts **6 months**. Learning is online: recorded video lessons, live webinars twice a week — on Mondays and Wednesdays at 7 pm Moscow time, and design reviews with a mentor. The recommended workload is 8–10 hours a week. You will need the free version of Figma.

## Portfolio projects

During the course you will complete 4 projects:

1. A mobile app redesign based on user research.
2. A landing page for an online service.
3. An online store with responsive versions and a design system.
4. A full-cycle final project on a brief from a real client.
